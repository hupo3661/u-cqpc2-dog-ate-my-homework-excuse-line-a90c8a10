One funny line for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty: a single line of under 200 characters in which the dog explains why the homework got eaten — he didn't eat it, he taste-tested it, and it failed.

`main.py` holds the line as a constant, validates it against the brief (one clean line, 1–200 characters, ending with a period), writes it to `/output/entry.txt`, and reads the file back to verify the write. It is deterministic, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
